# 🏥 Smart Healthcare Assistant

> **AI-Powered Personal Healthcare Companion**

**Smart Healthcare Assistant** is the flagship healthcare application under the **PulseNova** platform. It is an AI-powered healthcare management system developed to simplify personal healthcare by providing intelligent medicine reminders, symptom tracking, AI-powered health analysis, drug safety checking, health reports, caretaker support, medication planning, and personalized healthcare recommendations.

---

# 📖 Overview

Healthcare management often becomes difficult due to missed medicines, forgotten schedules, unrecorded symptoms, unsafe drug combinations, and lack of continuous health monitoring. Smart Healthcare Assistant addresses these challenges through an intelligent healthcare platform that assists users in managing their daily healthcare activities efficiently.

The application combines Artificial Intelligence with healthcare analytics to provide smart recommendations, medicine adherence monitoring, health trend analysis, PDF health reports, and intelligent healthcare assistance through a simple and interactive user interface.

---

# 🎯 Problem Statement

Patients frequently forget to take medicines on time, neglect symptom tracking, remain unaware of possible drug interactions, and find it difficult to monitor their overall health condition. Manual healthcare management often leads to medication errors, delayed treatment, and poor healthcare decisions.

Smart Healthcare Assistant provides an AI-powered solution that enables users to manage medicines, analyze symptoms, detect unsafe drug interactions, receive personalized health recommendations, monitor health progress, and improve overall healthcare management.

# 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/7sdhanush/PulseNova.git
```

### 2. Navigate to the Project Folder

```bash
cd PulseNova
```

### 3. Install Required Packages

```bash
pip install -r requirements.txt
```

### 4. Configure Gemini API Key

Create a `config.py` file and add:

```python
GEMINI_API_KEY = "YOUR_API_KEY"
```

### 5. Run the Application

```bash
streamlit run app.py
```

The application will open automatically in your default web browser.
